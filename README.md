# Controle Total — Otimizador de Windows

Este repositório guarda só os **instaladores** do Controle Total (aba *Releases*). O app confere aqui, uma vez por dia,
se existe versão nova e avisa; baixar e instalar é sempre com um clique de quem usa, e o arquivo é conferido pelo SHA-256
antes de rodar.

**Baixar:** abra a última versão em [Releases](../../releases/latest) e baixe `ControleTotal-Setup.exe`.

Requisitos: Windows 10 (1809) ou Windows 11, 64 bits. O app pede administrador porque ajusta configurações do sistema;
todo ajuste guarda o valor anterior e pode ser desfeito.
